## 线路核查：能验证的只有去程，回程 GIA 目前是商家口径

CN2 是中国电信的国际承载网，分 GT 和 GIA 两档，GIA 走 59.43 网段，晚高峰的拥堵明显少于普通 163 线路。这条线之所以被追，就是因为这个差别。

可以验证的部分是这样：第三方测评对圣何塞机房做过全国 ping 和去程路由跟踪，全国平均延迟约 168ms，非高峰时段文件下载能跑到 6MB/s 左右。广州电信的去程跳点依次是 59.43.46.77、59.43.138.46、59.43.38.162（上海）、59.43.182.181（圣何塞），末跳落在 145–146ms，全程确实走 59.43 段，这一段是实打实的 CN2 GIA。

问题出在回程。商家宣传的是"三网回程全部走 CN2 GIA，电信和联通去程也走 GIA，移动去程直连"。但那份第三方测评明确写了，由于机房的 Looking Glass 当时测不出回程，只测了去程。也就是说，**回程 GIA 目前只有商家和转述文章的说法，没有公开可查的第三方回程路由记录**。这不等于它是假的，但你在别处看到的"三网回程全 GIA 已实测"基本都是同一句话的复制。

移动和联通用户的去程体验也和电信不是一回事：

- 广州移动走 AS9808 普通直连，末段出现 cogentco.com（AS174）跳点，耗时 282–399ms，到服务器是 235–322ms。
- 广州联通先经 AS4837 到上海，再走 AS9929 出口到洛杉矶，最后回圣何塞，末跳 172.9–400.7ms，抖动偏大。

电信用户是这条线最舒服的一批，移动用户要有心理准备。

想自己确认，用官方测试入口：Looking Glass 是 `sjclg.akkocloud.com`，测速页在同域名的 `/speedtest` 路径下，测试 IP 有 45.9.10.70 和 45.9.10.146 两个（不同整理文章用的不是同一个）。建议晚上 8 点到 11 点测一次、白天再测一次，对比波动。晚高峰的表现才决定你日常用得顺不顺。

## 常见问题

**移动宽带用这条线会不会很难受？**
去程不走 GIA。第三方跟踪显示广州移动走 AS9808 直连，末段经 Cogent（AS174），到服务器 235–322ms，比电信的 145–146ms 高出一大截。移动用户如果能接受这个延迟，线路本身还是通的；如果对延迟敏感，建议先用测试 IP ping 一遍再决定。

**¥50 的 A1 到底是 512MB 还是 768MB？**
三种说法都存在：第三方列表普遍写 768MB，有一份写 1024MB，官网首页的 ¥50 展示位写 512MB 配 300Mbps。同一档套餐在不同页面显示不同参数，说明价格页本身有版本滞后。下单前在购物车页面确认实际配置，这是唯一可靠的办法。

**买了不满意能退吗？**
退款政策严格，官方条款明确不接受"不是原生 IP"作为退款理由。年付之前先月付，是这家最实际的规避方式。

**要不要先测速？**
要。用 `sjclg.akkocloud.com` 的 Looking Glass 和 45.9.10.146 这个测试 IP，在晚高峰和非高峰各测一次。你所在城市、所用运营商的实际表现，跟全国平均值可能差很多。
